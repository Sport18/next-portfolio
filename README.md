基于 [Next.js](https://nextjs.org) 的个人作品集项目，由 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 初始化。

## 技术大纲

完整技术栈、OpenSpec 工作流与功能路线图见 [docs/TECH-OUTLINE.md](docs/TECH-OUTLINE.md)。

## 本地开发

启动开发服务器：

```bash
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000) 查看效果。

## 开发流程

本项目使用 **OpenSpec + Superspec + Superpowers** 进行规格驱动开发。详见 [docs/TECH-OUTLINE.md](docs/TECH-OUTLINE.md#2-开发方法论)。

## 部署

推荐使用 [Vercel](https://vercel.com/new) 部署，详见 [Next.js 部署文档](https://nextjs.org/docs/app/building-your-application/deploying)。
